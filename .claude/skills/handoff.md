# Skill: Retomar desde handoff

Cuando el usuario diga "retomá", "continuá", "handoff", "seguí" o similar:

1. Leer PROGRESS.md — la última entrada describe el estado actual exacto
2. Leer SPEC.md — buscar el primer task [ ] pendiente en orden de prioridad
3. Confirmar al usuario antes de arrancar:
   - Qué task se va a encarar
   - Qué archivos se van a tocar
   - Estimación de complejidad: simple (1 archivo) / medio (2-3) / complejo (4+)
4. Esperar confirmación explícita del usuario
5. Ejecutar siguiendo el flujo definido en CLAUDE.md
