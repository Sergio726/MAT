## Errores Conocidos y Soluciones

### Error: "jQuery Migrate Warnings"
**Solución:** Revisar advertencias en consola. jQuery Migrate está incluido temporalmente para identificar código incompatible. Después de corregir, remover jQuery Migrate.

### Error: "Bootstrap classes not found"
**Solución:** Revisar cambios de clases CSS de Bootstrap 2 a Bootstrap 5. Ver guía de migración: https://getbootstrap.com/docs/5.3/migration/

### Error: "DataTables date-uk plugin not found"
**Solución:** El plugin fue removido. DataTables debería ordenar fechas automáticamente. Si hay problemas, considerar:
- Formatear fechas en formato ISO (YYYY-MM-DD) antes de mostrarlas
- O descargar el plugin date-uk localmente

### Error: "jQuery UI themes not loading"
**Solución:** Verificar que el CSS de jQuery UI esté en la ubicación correcta: `Content/themes/base/jquery-ui-1.13.2.css`
